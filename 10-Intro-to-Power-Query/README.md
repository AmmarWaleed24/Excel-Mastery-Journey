# ⚡ Lesson 10: Introduction to Power Query

## 🎯 Objectives
Learning how to connect, transform, and load data (ETL) without changing the original source.

---

## 🛠 Skills Applied
- **Get Data:** Importing data from Excel tables, CSV, or Folders.
- **Data Cleaning:** - Removing duplicate rows.
  - Trimming spaces (Trim/Clean).
  - Changing Data Types (e.g., converting Text to Date).
- **Column Management:** Removing unnecessary columns and reordering.
- **The "Refresh" Power:** Once the steps are saved, any new data added to the source can be cleaned instantly by clicking "Refresh".

## 📊 Practical Application
In the file `10-PowerQuery-Basics.xlsx`, I:
1. Imported a "Messy" sales dataset.
2. Cleaned it using the Power Query Editor.
3. Loaded the clean version into a new sheet.
