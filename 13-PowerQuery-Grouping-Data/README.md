# 📊 Lesson 13: Grouping & Aggregating Data

## 🎯 Objectives
Summarizing large datasets directly within the data transformation layer to improve workbook performance.

---

## 🛠 Skills Applied
- **Basic Group By:** Grouping data by one column (e.g., Total Sales by Region).
- **Advanced Group By:** Grouping by multiple levels (e.g., Total Sales by Region AND Category).
- **Operations:** Calculating Sum, Average, Median, and Row Counts during the grouping process.

## 📊 Practical Application
In the file `13-Grouping-Basics.xlsx`, I:
1. Grouped a detailed transaction list to show only the total daily revenue.
2. Filtered out low-performing categories before loading the data into the final dashboard.
