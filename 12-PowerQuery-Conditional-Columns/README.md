# ⚡ Lesson 12: Advanced Columns in Power Query

## 🎯 Objectives
Learning how to create new data attributes using logic and custom formulas within the Power Query Editor.

---

## 🛠 Skills Applied
- **Conditional Columns:** Creating "If-Then-Else" logic visually without writing code.
- **Custom Columns:** Using basic arithmetic across columns (e.g., [Price] * [Quantity]).
- **Column from Examples:** A powerful AI feature where you type a few examples of what you want, and Excel figures out the pattern for you.

## 📊 Practical Application
In the file `12-Conditional-Columns.xlsx`, I:
1. Created a "Performance" column based on sales targets.
2. Used "Column from Examples" to extract the first name from a full name column.
